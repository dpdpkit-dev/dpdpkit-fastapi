dpdpkit admin

The admin dashboard ships in v0.4. Until then, use the admin API under this mount's parent path:

  • GET ../requests — request queue
  • GET ../retention/preview — upcoming warnings and erasures
  • POST ../ledger/verify — hash-chain check
  • GET ../audit/export — evidence pack
